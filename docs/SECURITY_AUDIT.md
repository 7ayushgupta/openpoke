### 2. **OAuth State Parameter Not Validated - CRITICAL**
**Location:** `server/routes/auth.py:46-50`

**Issue:** The OAuth callback accepts a `state` parameter but **NEVER VALIDATES IT**, making the system vulnerable to CSRF attacks.

```python
@router.get("/callback")
async def oauth_callback(
    code: str = Query(...),
    state: str = Query(...)  # ⚠️ Received but NEVER validated!
):
    # No validation that this state was generated by the server
    token_response = await oauth_service.exchange_code_for_token(code)
```

**Attack Scenario:**
1. Attacker initiates OAuth flow and captures their authorization code
2. Attacker tricks victim into clicking a crafted callback URL with the attacker's code
3. Victim's session is linked to attacker's Google account
4. Attacker can access victim's session

**Impact:**
- ⚠️ **Account Takeover:** Attackers can hijack user sessions
- ⚠️ **CSRF Attack:** Bypass OAuth security protections
- ⚠️ **Session Fixation:** Link victim's session to attacker's account

**Fix Required:**
```python
# Add state storage (Redis or database)
class OAuthStateStore:
    def __init__(self):
        self._states = {}  # Use Redis in production
    
    def create_state(self, user_id: Optional[str] = None) -> str:
        state = secrets.token_urlsafe(32)
        self._states[state] = {
            "created_at": datetime.utcnow(),
            "user_id": user_id
        }
        return state
    
    def validate_and_consume_state(self, state: str) -> bool:
        if state not in self._states:
            return False
        state_data = self._states.pop(state)
        # Check expiration (5 minutes)
        if datetime.utcnow() - state_data["created_at"] > timedelta(minutes=5):
            return False
        return True

# In callback:
if not oauth_state_store.validate_and_consume_state(state):
    raise HTTPException(
        status_code=status.HTTP_400_BAD_REQUEST,
        detail="Invalid or expired state parameter"
    )
```

### 3. **JWT Secret Key Auto-Generation - HIGH**
**Location:** `server/services/auth/jwt_service.py:31-43`

**Issue:** If `JWT_SECRET_KEY` is not set, a random key is generated **at runtime**. This means:
- All tokens become invalid on server restart
- Different server instances have different keys (breaks load balancing)
- No warning to users that they're using an insecure configuration

```python
def _get_or_generate_secret_key(self) -> str:
    secret_key = self.settings.jwt_secret_key
    if not secret_key:
        # ⚠️ Generates a NEW key every restart!
        secret_key = secrets.token_urlsafe(32)
        logger.warning("JWT_SECRET_KEY not set, generated a new one.")
    return secret_key
```

**Impact:**
- ⚠️ **Session Loss:** All users logged out on every restart
- ⚠️ **Load Balancer Issues:** Multi-instance deployment will fail
- ⚠️ **Production Risk:** Silent failure in cloud deployments

**Fix Required:**
```python
def _get_or_generate_secret_key(self) -> str:
    secret_key = self.settings.jwt_secret_key
    if not secret_key:
        # ⚠️ FAIL LOUDLY in production
        if os.getenv("ENVIRONMENT") == "production":
            raise RuntimeError(
                "JWT_SECRET_KEY is required in production. "
                "Generate one with: python -c 'import secrets; print(secrets.token_urlsafe(32))'"
            )
        logger.error("JWT_SECRET_KEY not set - using temporary key")
        secret_key = secrets.token_urlsafe(32)
    return secret_key
```

### 4. **No Rate Limiting - HIGH**
**Location:** Entire API surface

**Issue:** There is **NO rate limiting** on any API endpoint, allowing:
- Brute force attacks on authentication
- DoS attacks by flooding endpoints
- Resource exhaustion
- Abuse of LLM API calls (expensive!)

**Vulnerable Endpoints:**
- `/api/v1/auth/login` - Can be spammed to exhaust OAuth quotas
- `/api/v1/auth/callback` - No protection against brute force
- `/api/v1/chat/send` - Unlimited LLM API calls ($$$ expensive)
- `/api/v1/admin/status` - Can be scraped continuously

**Impact:**
- ⚠️ **DoS Attacks:** System can be taken offline
- ⚠️ **Cost Explosion:** Unlimited LLM calls = huge bills
- ⚠️ **Brute Force:** No protection against password/token guessing

**Fix Required:**
```python

# Sanitize logs
def sanitize_for_logging(email: str) -> str:
    """Mask email for logging: john.doe@example.com -> j***e@example.com"""
    if "@" not in email:
        return "***"
    local, domain = email.split("@", 1)
    if len(local) <= 2:
        masked_local = "*" * len(local)
    else:
        masked_local = local[0] + "*" * (len(local) - 2) + local[-1]
    return f"{masked_local}@{domain}"
```

```python
async def add_security_headers(request: Request, call_next):
```

### 14. **No Request Size Limits**
Prevent DoS via large payloads:

```python
from fastapi.middleware import Middleware
from starlette.middleware.base import BaseHTTPMiddleware

class RequestSizeLimitMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        if request.method in ["POST", "PUT", "PATCH"]:
            content_length = request.headers.get("content-length")
            if content_length and int(content_length) > 10_000_000:  # 10MB limit
                return JSONResponse(
                    {"error": "Request too large"},
                    status_code=413
                )
        return await call_next(request)

app.add_middleware(RequestSizeLimitMiddleware)
```
